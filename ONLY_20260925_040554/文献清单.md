# CAP 方法精炼文献清单

日期：2026-09-25

## 1. 当前失败模式与检索标准

当前 CAP-C 的固定协议证据是：

```text
a_i = cos(p_i, h_visual) - cos(p_i, h_blank)
```

这个差分比原始 cosine attribution 更有区分度，但仍把同一组 feature probe
固定用于整个自回归序列。已观察到的失败不是“没有视觉信号”，而是干预策略没有
区分 token 风险：CHAIR-64 的 gain 曲线相邻最大波动为 `0.15625`，CAP-C
完整 CHAIR-500 的 CHAIRs 虽下降，但 CHAIRi/Recall 下降；POPE-3000 四项
指标也略低于 Vanilla。检索因此集中在以下相同或相近失败模式：

1. 视觉信息被语言先验替代，或随自回归长度衰减。
2. 固定强度 contrastive/probe 会把正确 token 和幻觉 token 一起改写。
3. 需要 token 级或 step 级的可靠性判断，而不是全局固定 gain。
4. 硬候选截断可能把 sampling 退化成贪心，造成表面 POPE 收益而不是真实 grounding。

以下条目优先保留有顶会正式版本、DOI/PMLR 或官方 arXiv 元数据可核验的论文。
论文链接均指向论文原文或正式出版页面；公式中明确区分“论文原式”和“本项目借鉴
后的改造式”。

## 2. 直接相关的顶会方法

### 2.1 VCD：视觉不确定性反事实对比

- **论文**：Sicong Leng et al., *Mitigating Object Hallucinations in Large
  Vision-Language Models through Visual Contrastive Decoding*。
- **会议/链接**：CVPR 2024，正式 DOI
  [10.1109/CVPR52733.2024.01316](https://doi.org/10.1109/CVPR52733.2024.01316)；
  [arXiv:2311.16922](https://arxiv.org/abs/2311.16922)；官方代码
  [DAMO-NLP-SG/VCD](https://github.com/DAMO-NLP-SG/VCD)。
- **同类失败模式**：视觉被扰动或不确定时，语言模型的 statistical/unimodal
  prior 变强，直接使用 clean logits 会产生对象幻觉。
- **论文核心组件**：原图与加噪/失真图各做一次 forward，在 logit 空间对比，并用
  clean 分支约束候选集合：

  ```text
  l_vcd(w) = (1 + alpha) l_visual(w) - alpha l_distorted(w)
  V_head = {w : p_visual(w) >= beta * max_u p_visual(u)}
  ```

- **CAP 借鉴**：CAP-C 已经在 feature 空间做 `visual - blank`；本轮不照搬
  VCD 的固定 `alpha`，而是把它改成由当前 token 的分支分歧和熵变化决定的
  `alpha_t`，并把硬 `V_head` 改成 soft plausibility gate，避免硬截断。

### 2.2 HALC：token 级自适应 focal-contrast grounding

- **论文**：Zhaorun Chen et al., *HALC: Object Hallucination Reduction via
  Adaptive Focal-Contrast Decoding*。
- **会议/链接**：ICML 2024，PMLR 235，
  [arXiv:2403.00425](https://arxiv.org/abs/2403.00425)，
  [PMLR 235](https://proceedings.mlr.press/v235/chen24n.html)，官方代码
  [BillChan226/HALC](https://github.com/BillChan226/HALC)。
- **同类失败模式**：固定全图视觉上下文不能保证每个对象 token 都得到合适的
  局部证据；生成越长，错误 token 会逐步累积。
- **论文核心组件**：按当前 token 重新评估多个局部 field-of-view，用 JSD 选择
  分歧最大的视觉上下文对，再做双向 contrast；同时以全局视觉匹配保留整体质量。
  其局部分歧选择可概括为：

  ```text
  d(v_i, v_j) = JSD(p(.|v_i) || p(.|v_j))
  (i, j) = top_m_pairs d(v_i, v_j)
  ```

- **CAP 借鉴**：不引入 detector、crop 或 beam search，因为这会违反 ONLY 的
  “无新模型/固定协议”边界；只借鉴其“按 token 判断是否值得干预”。CAP-R 用
  `JSD(base, probe)` 作为视觉分歧信号，并要求 probe 同时降低熵，才提高当前步
  的干预强度。

### 2.3 OPERA：过度信任惩罚与回溯分配

- **论文**：Qidong Huang et al., *OPERA: Alleviating Hallucination in
  Multi-Modal Large Language Models via Over-Trust Penalty and
  Retrospection-Allocation*。
- **会议/链接**：CVPR 2024，
  [arXiv:2311.17911](https://arxiv.org/abs/2311.17911)，官方代码
  [shikiw/OPERA](https://github.com/shikiw/OPERA)。
- **同类失败模式**：长序列中后续 token 过度依赖少数 summary token，逐步忽略
  图像 token；错误具有滞后性，等发现时已经污染后续生成。
- **论文核心组件**：用 attention 的 column-wise aggregation 构造 over-trust
  penalty，再对候选序列降权；若多个时间步反复指向同一 summary 位置，则回溯
  并重新分配候选。论文中的局部惩罚形式为：

  ```text
  phi(omega_<t) = product_{i=c}^{t-1} (sigma * omega_{i,c})
  l'(w) = l(w) - alpha * phi(omega_<=t)
  ```

- **CAP 借鉴**：把“发现过度信任后降低干预/回到安全分支”的思想用于 CAP；
  当前实现采用每步软回退到 Vanilla 的 `lambda_t`，而不是实现 beam rollback，
  以保持 sampling、batch 和推理成本可比。

### 2.4 DoLa：动态层间对比用于事实性

- **论文**：Yung-Sung Chuang et al., *DoLa: Decoding by Contrasting Layers
  Improves Factuality in Large Language Models*。
- **会议/链接**：ICLR 2024，
  [arXiv:2309.03883](https://arxiv.org/abs/2309.03883)，官方代码
  [voidism/DoLa](https://github.com/voidism/DoLa)。
- **同类失败模式**：最终层的语言分布可能仍包含表面上合理但错误的先验；不同
  token 需要不同强度的层间对比。
- **论文核心组件**：对每个 token 动态选择与 mature layer JSD 最大的 premature
  layer，再做 log-probability contrast：

  ```text
  M_t = argmax_j JSD(q_final,t || q_j,t)
  q_hat_t = softmax(log q_final,t - log q_M_t)
  ```

- **CAP 借鉴**：不把 LLaVA 的中间层当作可靠视觉分支，而借鉴“分歧用于动态
  选择”的原则；CAP-R 的 `JSD` 是 `base/probe` 两个视觉输入路径的在线分歧。

### 2.5 RVCD：检索视觉正/负证据的 contrastive decoding

- **论文**：Jihoon Lee and Min Song, *Retrieval Visual Contrastive Decoding
  to Mitigate Object Hallucinations in Large Vision-Language Models*。
- **会议/链接**：ACL 2025 Findings camera-ready，
  [arXiv:2505.20569](https://arxiv.org/abs/2505.20569)，官方代码
  [JiHoonLee9898/RVCD](https://github.com/JiHoonLee9898/RVCD)。
- **同类失败模式**：单一 distorted negative 可能不能稳定代表某个对象的错误
  视觉证据；需要正/负视觉参照提升 contrast 的 specificity。
- **核心组件**：以检索或构造的 positive/negative concept image 形成视觉
  contrastive logits，而不是只依赖一条 clean 分支。
- **CAP 借鉴与边界**：本项目不引入检索库或生成图片，避免外部数据和新模型；保留
  CAP 的 blank counterfactual 作为零成本 negative reference，并通过可靠性门
  抑制不稳定的单一差分。

## 3. 与 CAP-R 直接对应的近期证据

### 3.1 SAFE：视觉依赖衰减与 token 级反事实分数

- **论文**：Zhipeng Zhao et al., *What Do Hallucinations Reveal About
  Multimodal Reasoning? Diagnosing Visual Grounding Failures via Contrastive
  Decoding Probes*。
- **链接/状态**：[arXiv:2609.16646](https://arxiv.org/abs/2609.16646)，arXiv
  元数据显示为 EMNLP 2026 论文。
- **关键发现**：对 visually-grounded 与 vision-ablated generation path 做
  token-level contrastive grounding score；视觉依赖随生成位置衰减，幻觉会形成
  temporal clusters，早期干预通常比晚期强行纠偏更有效。
- **CAP 借鉴**：CAP-C 的 blank hidden 对照与 SAFE 的 vision-ablated probe
  同属反事实家族；CAP-R 进一步把干预量变成每步 `lambda_t`，而不是固定整段
  probe 强度。由于该条目截至本报告日期是新近 arXiv/会议记录，结果只作为方法
  设计依据，不作为本仓库的外部性能保证。

### 3.2 SAVAA：step-wise adaptive visual amplification

- **论文**：Jiacheng Zhang et al., *SAVAA: Mitigating Hallucinations in LVLMs
  via Step-wise Adaptive Visual Attention Amplification*。
- **链接**：[arXiv:2602.13600](https://arxiv.org/abs/2602.13600)。
- **关键机制**：指出固定 visual amplification 在低风险步过强、在高风险步又
  可能不足；以 predictive entropy 与 visual grounding 组成 Visual Grounding
  Entropy，再按步调整 amplification。
- **CAP 借鉴**：CAP-R 使用 probe 前后 entropy difference 作为无标签风险/可靠性
  代理，并把它与 JSD 相乘，要求“有视觉分歧且 probe 更集中”才放大 probe。
  这避免把单纯高分歧当成可靠证据。

## 4. 反例与设计约束

### 4.1 Contrastive decoding 不能只看 POPE 点估计

- **论文**：Hao Yin et al., *The Mirage of Performance Gains: Why Contrastive
  Decoding Fails to Mitigate Object Hallucinations in MLLMs?*，
  [arXiv:2504.10020](https://arxiv.org/abs/2504.10020)。
- **核心警告**：某些 contrastive 方法的 POPE 增益可能来自单向分布偏移和硬
  adaptive plausibility constraint，后者会把 sampling 近似成 greedy，不能自动
  解释为 grounding 变好。
- **CAP-R 约束**：不使用硬 `-inf` mask；只用连续 soft gate，保持完整词表概率
  支持。报告同时列出 CHAIR、CHAIRi、Recall 和 POPE 四项指标，不以 POPE 单项
  提升作为成功标准。

## 5. 本轮采用的 CAP-R 改造公式

CAP-C 的 feature probe 保持不变：

```text
a_i = cos(p_i, h_visual) - cos(p_i, h_blank)
x'_i = EnergyPreservingProbe(x_i, a_i, eta)
```

新增只发生在解码端。令 `z_t` 为 Vanilla/base logits，`z'_t` 为 CAP-C
probed-feature logits，`p_t=softmax(z_t)`、`q_t=softmax(z'_t)`：

```text
J_t       = JSD(p_t || q_t)
DeltaH_t  = (H(p_t) - H(q_t)) / log(|V|)
r_t       = sigmoid((J_t - j0) / tau_J)
            * sigmoid(DeltaH_t / tau_H)
lambda_t  = lambda_max * r_t
g_t(w)    = sigmoid((log p_t(w) - max_u log p_t(u) - log(beta)) / tau_P)

log q_R,t(w) = log p_t(w)
               + lambda_t * g_t(w) * (log q_t(w) - log p_t(w))
```

解释：

- `J_t` 借鉴 VCD/HALC/DoLa 的“分支分歧是需要重新判断的信号”；
- `DeltaH_t` 借鉴 SAVAA 的 uncertainty-aware step control。若 probe 使分布
  更不确定，CAP-R 自动回退；
- `g_t(w)` 是 VCD/DoLa APC 的软版本，保留 clean 分支支持但不硬删除 token；
- `lambda_t` 只控制当前步，避免 CAP-C 的静态 feature intervention 在整段序列
  上持续放大；`lambda_t=0` 时严格退化为 Vanilla。

该公式不引入新模型、新数据、新 caption 或训练参数。它是对已有 CAP-C 两分支
的后处理，且所有方法仍使用相同模型、prompt、seed、采样和资源。

## 6. 明确不采用的组件

| 方法组件 | 不采用原因 |
|---|---|
| HALC detector/FOV/beam search | 引入额外 detector 和 beam/search 成本，改变固定 sampling 协议 |
| RVCD 检索正负图像 | 引入检索库或生成图像，不再是零外部依赖 CAP |
| OPERA beam rollback | 当前 runtime 是 sampling cache，加入 rollback 会改变协议且需重算 KV cache |
| DoLa 中间层 logits | LLaVA 的多模态中间层语义未验证，且会破坏 CAP 的单一机制归因 |
| 硬 APC / top-k 词表截断 | 与 CHAIR 长文本及近期 reproducibility warning 冲突 |
| CLIP/GTP caption 融合 | 会把 CAP 变成混合方法，无法识别 CAP 自身是否修复失败模式 |

## 7. 参考与实验解释边界

这些论文提供机制启发，不构成 CAP-R 在 LLaVA-1.5-7B 上的效果保证。CAP-R 是否
可行只由本仓库固定的 SHIELD-compatible CHAIR-500 和 POPE adversarial-3000
实验决定；任何 CHAIR-64 参数筛选都只用于选择候选参数，不能单独作为最终性能声明。
